# stark/ — transparent STARK segments for class-group `reduce`

Rust prototypes that arithmetize pieces of the **reduction step** of binary
quadratic forms (imaginary quadratic class groups, 2048-bit discriminant) as
STARK constraints. Built on [Winterfell](https://github.com/facebook/winterfell)
0.8.3 over the Goldilocks field with a quadratic extension, FRI commitments,
Blake3. No trusted setup anywhere.

Each binary builds a trace, produces a proof, verifies it with Winterfell's
native verifier, and then runs negative tests (tampered inputs or a corrupted
proof) that must be rejected. A binary exits non-zero if any check fails.

## Run

```bash
cd stark
./run_all.sh            # builds all binaries, runs all 22 proof modules and the prover
# or a single segment:
cargo run --release --bin mulseg_b
```

Data files in `data/` are real 2048-bit values (forms, `a·c`, `b²`, `|D|`)
generated by `python-demo/measure_reduce_depth.py`. `data/trajectory.txt` is
produced by `python-demo/emit_trajectory.py` (deterministic; regenerating it
gives the same file) and is read by `prover`.

### Assembled modules

All use one shared LogUp table `[0, 2^16)` (trace length 65536), a full-degree
counter column, and 108-bit conjectured security.

| binary | what it shows | input data | cols | proof |
|---|---|---|---|---|
| `round_full` | one rho round at 64 limbs: `P = k·B` with carry, normalization `W = A' − \|B'\|`, all range checks through LogUp | deterministic pseudo-random limbs | 21 | 107 KB |
| `reduce_chain` | 228 rounds chained in one trace: round boundaries bound, `4ac − b² = \|D\|` checked every round | small toy form (a=380, b=241, c=7146) cycled with k = 0 | 15 | 104 KB |
| `reduce_merged` | 228 blocks of 64-limb arithmetic chained; `c(r) = a(r+1)` limb-wise via a grand-product permutation argument | synthetic limbs | 23 | 109.5 KB |
| `perm_bind` | the permutation argument on its own | synthetic | — | 63 KB |
| `disc_anchor` | `4ac − b² = \|D\|` on a real 2048-bit form | `data/anchor128.txt` | 19 | 107.6 KB |
| `disc_full` | `\|D\|` derived inside the trace from a, b, c (multiplication phases + anchor), L = 4 demo | synthetic | 42 | 73.8 KB |
| `disc_full_l64` | the same at full width (L = 64, 1024-bit operands, 2048-bit products) | pseudo-random a, b, c | 160 | 152.7 KB |
| `prover` | builds the `disc_anchor` proof for a real reduced form and writes an `MLK1` receipt | `data/trajectory.txt` | — | 108 KB receipt |

`*_vectors` binaries print test vectors from Winterfell internals (field,
transcript, Merkle, DEEP, FRI) for the Solidity verifier parts in
`solidity/stark-verifier/`. They do not prove anything.

Limbs are 16-bit. Sizes are from the reruns on 2026-10-10
(`measurements/rerun-2026-10-10*.txt`); the original August outputs are in the
`measurements/rezultati-*.txt` files and agree with them.

## Status and limits

- **Proven with negative tests:** the arithmetic building blocks of a rho
  round at full 2048-bit width (multiplication, signed arithmetic,
  normalization), the discriminant relation `4ac − b² = |D|` with `|D|`
  computed inside the trace, LogUp range checks, and the chaining machinery
  (boundary binding, permutation argument) at the scale of a full reduce.
- **Not proven: a correct reduce of a real form.** `reduce_chain` chains a
  toy form with k = 0. In `reduce_merged`, the new `b'` is a free witness that
  is not constrained to equal `2kc − b`, and there is no discriminant check.
  The real-data trajectory used by `prover` has a single round.
- **Not done:** composition (NUCOMP / xgcd), the VDF squarings, and
  Wesolowski verification over the class group. This code does not prove a
  Wesolowski proof.
- **Prover and e2e:** `prover` generates a proof but does not verify it.
  `python-demo/e2e_test.py` checks the receipt format, `sec ≥ 95` and the
  anchor public inputs; it does not verify the STARK proof.
- **On-chain verifier:** `solidity/stark-verifier/` holds the five verifier
  parts and a `MintLockVerifier` entry point. They compile with solc 0.8.24,
  but the full `verify()` orchestration and Blake3 in Solidity are not
  written, nothing has been deployed, and no gas has been measured. Gas
  figures in `docs/` (~3.3–5.8M per proof, ~810k for the skeleton) are
  projections.
- **Security** numbers printed by the binaries (~109–121 bits) are Winterfell's
  *conjectured* security. Proven security is lower (e.g. 74 bits for
  `stark-poc`).
- Toolchain: originally built with rustc 1.75; rebuilt and passing with
  rustc 1.97 using the pinned `Cargo.lock`.
